# Sumit Neupane — Plain HTML/CSS Portfolio



## Files
- `index.html` — page content and structure
- `style.css` — design and responsive styling
- `script.js` — menu, theme, role animation, filters, contact form
- `resume.html` — printable resume page

## Run
Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

## Personalize
Edit `portfolioEmail` and `portfolioLinkedIn` at the top of `script.js`. Update your college and study period in `index.html`, add actual repository links, and replace placeholders in `CV`.

The contact form uses `mailto:` and opens the visitor's email application. It does not submit to a server.
